# 地心实验室：万物锻造炉 - 科学依据与技术方案

## 一、 科学判定依据、数学公式与文献支撑

为了确保“地心实验室”模块绝对严谨、不产生任何科学误导，本模块摒弃游戏化的“抽象数值”，转而使用真实的物理单位，并以国际公认的地球物理学标准模型作为底层判定逻辑。

### 1. 核心科学文献与底层数据模型

本模块的所有环境数据（深度、温度、压力、密度）均严格基于以下权威科学模型：

- **PREM模型 (Preliminary Reference Earth Model)**
  - **文献来源：** Dziewonski, A. M., & Anderson, D. L. (1981). *Physics of the Earth and Planetary Interiors*.
  - **应用：** 国际公认的地球内部结构标准模型。实验室中每一千米深度的**环境密度 \(\rho\)** 和 **静水压力 \(P\)** 均由该模型的数据表插值计算得出。
- **地球内部地温梯度模型 (Geothermal Gradient)**
  - **文献来源：** Stacey, F. D. (1992). *Physics of the Earth*. / Anzellini, S., et al. (2013). *Science* (关于地核熔点的最新测定).
  - **应用：** 决定不同深度的**真实温度 \(T\)**。
- **“地心探测器”理论 (Mission to Earth's Core)**
  - **文献来源：** Stevenson, D. J. (2003). *Nature*.
  - **防误导关键点：** 很多科普常犯的错误是“把石头扔进地幔会像沉入水里一样”。**实际上地幔是固态岩石（具塑性）**。实验室的背景设定参考 Stevenson 的方案：**样本必须具有极高的密度和热量，通过“重力破裂”或“局部熔融”的方式在固态地幔中下沉。**

### 2. 用户参数与判定公式 (The Physics Engine)

用户调节的三个滑块对应真实的物理量，系统的“生死判定”完全基于物理公式：

#### A. 密度 (Density, \(\rho\)) —— 决定能否沉入深层
- **物理单位：** \(g/cm^3\) (克/立方厘米)。用户可调范围：\(1.0 \sim 22.6\)。
- **科学依据：** 阿基米德浮力原理与 PREM 密度分层。
- **判定公式：** 样本在深度 \(z\) 处继续下沉的条件是：
  \[ \rho_{sample} > \rho_{earth}(z) \]
- **硬核表现：** 如果用户设定的密度是 \(8.0\ g/cm^3\)（类似钢铁），它一接触到液态外核 (\(9.9\ g/cm^3\)) 就会像木头浮在水面上一样悬浮在核幔边界。只有密度 \(> 12.2\ g/cm^3\) 的物质才能沉入内核。

#### B. 熔点 (Melting Point, \(T_m\)) —— 决定是否被气化/熔融
- **物理单位：** \(^\circ C\) (摄氏度)。用户可调范围：\(0 \sim 4000^\circ C\)。
- **科学依据：** 物质的熔点随压力升高而升高（克拉珀龙方程）。
- **判定公式：** 引入简化的 **Simon-Glatzel 方程** 来计算样本在当前深度的实际熔点：
  \[ T_m(P) = T_{m0} \left(1 + \frac{P(z)}{a}\right)^b \]
  **销毁判定：** 当环境温度 \(T_{earth}(z) > T_m(P)\) 时，样本熔毁。
- **硬核表现：** 地核温度高达 \(5000 \sim 6000^\circ C\)，单靠常压高熔点是不够的，必须依赖深层极高压力 \(P(z)\) 对熔点的提升作用才能存活。

#### C. 体积模量/抗压强度 (Bulk Modulus, \(K\)) —— 决定是否被压碎
- **物理单位：** \(GPa\) (吉帕斯卡)。用户可调范围：\(10 \sim 500\ GPa\)。
- **科学依据：** 地球内部的静水压力分布。
- **判定公式：** 深度的环境压力积分公式：
  \[ P(z) = \int_{0}^{z} \rho(h) g(h) dh \]
  **销毁判定：** 当环境压力 \(P(z) > K_{sample}\) 时，样本晶格崩塌（碎裂）。
- **硬核表现：** 地心压力高达 \(360\ GPa\)。如果用户选择类似石英的强度（约 \(37\ GPa\)），在进入下地幔时就会瞬间粉碎。

### 3. 数据驱动表 (Lookup Table)

为了在移动端高性能实现，将复杂的微积分简化为深度映射查找表，并在运行时使用**线性插值 (Linear Interpolation)** 算出当前精确的温度、压力和密度。

```swift
struct EarthLayerData {
    let depth: Double       // 深度 (km)
    let temperature: Double // 温度 (°C)
    let pressure: Double    // 压力 (GPa)
    let density: Double     // 密度 (g/cm³)
    let state: MatterState  // 固态/液态/塑性
}

// 基于 PREM 和 Stacey (1992) 模型的关键节点数据
let earthProfile: [EarthLayerData] = [
    EarthLayerData(depth: 0, temperature: 15, pressure: 0.0001, density: 2.7, state: .solid),
    EarthLayerData(depth: 35, temperature: 600, pressure: 1.0, density: 3.3, state: .solid), // 莫霍面
    EarthLayerData(depth: 660, temperature: 1600, pressure: 24.0, density: 4.4, state: .plastic), // 上下地幔边界
    EarthLayerData(depth: 2890, temperature: 3700, pressure: 136.0, density: 5.5, state: .plastic), // 核幔边界(地幔侧)
    EarthLayerData(depth: 2891, temperature: 3750, pressure: 136.0, density: 9.9, state: .liquid), // 核幔边界(外核侧)
    EarthLayerData(depth: 5150, temperature: 4300, pressure: 330.0, density: 12.2, state: .liquid), // 内外核边界
    EarthLayerData(depth: 6371, temperature: 5500, pressure: 360.0, density: 13.1, state: .solid) // 地心
]
```

## 二、 整体技术方案

### 1. 技术栈选型
本项目采用 **“UIKit (外壳与控制) + SpriteKit (核心物理与渲染)”** 的混合架构。
- **UI 与交互层 (UIKit)：** 完美融入现有项目架构。利用 `UISlider`、`UILabel`、`UIButton` 快速构建控制面板和数据仪表盘，开发成本极低。
- **物理模拟与动画层 (SpriteKit)：** 传统 `UIView` 动画无法处理复杂的重力、动态阻力、浮力以及粒子特效。SpriteKit 自带高性能的 `SKPhysicsWorld` 和 `SKEmitterNode`，能以极少的代码量实现逼真的物理下落与销毁特效。
- **数据通信 (Delegate 模式)：** 通过协议实现 SpriteKit 场景与 UIKit 视图控制器的单向数据流通信，解耦物理逻辑与 UI 渲染。

### 2. 核心架构设计
- **数据模型层 (`EarthPhysicsEngine`)：** 内置 PREM 深度映射查找表，提供 `getEnvironment(at depth: Double)` 方法进行线性插值计算。
- **物理渲染层 (`LaboratoryScene : SKScene`)：**
  - 在 `update` 循环中根据 `position.y` 换算深度，动态调整 `physicsBody.linearDamping` (阻力) 或施加 `applyForce` (浮力)。
  - 触发熔化或碎裂逻辑时，调用 `removeFromParent()` 并添加 `SKEmitterNode` 播放特效。
- **视图控制层 (`LaboratoryViewController : UIViewController`)：** 承载 `SKView`，并在顶层覆盖 UIKit 控件，将用户设定的参数传递给 Scene 启动物理引擎。

### 3. 页面视觉组成与高级感 UI
整个页面采用 **“全屏沉浸式背景 + 悬浮半透明控制台”** 的设计（类似 HUD 平视显示器）：
- **第一层 (SpriteKit 层)：** 全屏沉浸式物理视界，背景颜色随深度渐变，展示样本下落、拖尾、爆炸、气化等核心视觉特效。
- **第二层 (顶部 HUD 仪表盘)：** 使用 `UIVisualEffectView(effect: UIBlurEffect(style: .dark))` 制作深色毛玻璃背景，配合等宽数字字体 (Monospaced Digit) 和荧光色 (Cyan/Green) 展示实时深度、温度、压力。
- **第三层 (底部锻造控制台)：** 同样采用深色毛玻璃背景。通过自定义 `UISlider` 的轨道颜色，并使用系统自带的 SF Symbols (如 `thermometer`, `scalemass.fill`) 替换默认滑块圆点，结合 `UISelectionFeedbackGenerator` 提供触觉震动反馈，低成本打造极具科幻感的高级 UI。
